# Product roadmap

This is a proposed readiness roadmap, not a committed delivery schedule.

## Phase 1 — Make the prototype understandable
- Keep README and product documentation aligned with the code.
- Capture current screenshots and annotate core journeys.
- Inventory routes and feature status.
- Run a responsive and accessibility review.

**Exit evidence:** documented screens, verified feature inventory and prioritised UX issues.

## Phase 2 — Establish production foundations
- Define user, profile and role data model.
- Implement real authentication and session lifecycle.
- Enforce permissions at the database and server boundaries.
- Define product, order, wallet and payout data contracts.
- Add environment and secret-management guidance.

**Exit evidence:** tested auth flows, role-policy tests and documented service contracts.

## Phase 3 — Complete core user journeys
- Learner discovery and access.
- Creator product creation and publishing.
- Affiliate promotion and performance.
- Events, bookings and support workflows.

**Exit evidence:** end-to-end tests against a staging backend and clear recovery states.

## Phase 4 — Validate and improve
- Conduct usability sessions with each user group.
- Instrument agreed activation and conversion events.
- Review support issues and funnel drop-offs.
- Prioritise improvements using evidence.

**Exit evidence:** research findings, baseline metrics and an updated prioritised backlog.
